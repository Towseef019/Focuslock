# FocusLock

**FocusLock is an Android-focused study and productivity app designed to help you stay off distracting apps while you work toward a study goal.**

The idea is simple: set a focus session, keep your attention on studying, and make it harder to drift into apps that eat your time.

## Goals

- Start a focused study session with a timer or target duration.
- Reduce access to distracting apps during a session.
- Keep essential communication available where Android permissions and the app's implementation allow it.
- Make focused study sessions easier to start and stick with.

## Project status

This repository is a work in progress. Features and device compatibility may change as development continues. Check the source code and latest commits for the current implementation; features described as goals above may not all be implemented yet.

## Installation

No verified release APK or installation package is documented here yet.

For development, clone or download this repository and follow the build instructions for the Android project files included in the repository. If build instructions are not present, the project may need additional setup before it can be built.

## Permissions and limitations

App blocking and restrictions on other apps depend on Android version, granted permissions, and the implementation. Android may restrict background activity and some forms of app control. FocusLock should not be assumed to block every distraction or override the operating system.
